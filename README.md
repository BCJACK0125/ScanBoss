# 傳統超市智慧掃碼助手 (Smart Supermarket Scanner) - MVP

> **將手機變身為強大的 POS 機，專為傳統柑仔店與中小型超市設計的數位化解決方案。**

## 1. 專案背景與前因後果

### 🛑 痛點分析 (The Problem)
在台灣及許多亞洲地區，仍存在大量傳統超市與柑仔店。這些店家通常面臨以下挑戰：
*   **數位化程度低**：依賴人腦記帳或紙本紀錄，容易出錯。
*   **設備成本高昂**：傳統 POS 機硬體昂貴，且軟體訂閱費用對小本生意是一大負擔。
*   **庫存管理混亂**：不清楚哪些商品即將過期，也不確定哪些商品是真正的「熱銷獲利王」。
*   **利潤計算模糊**：往往只看每天收了多少錢（營收），卻忽略了進貨成本，導致不知實際淨利（毛利）為何。

### 💡 解決方案 (The Solution)
本專案旨在開發一個 **「零成本、無需安裝、離線優先」** 的輕量級網頁應用程式 (Web App)。
透過 HTML5 技術調用手機攝像頭，直接辨識商品條碼，實現掃碼結帳、進貨管理、庫存預警與財務分析一條龍服務。讓老闆用自己現有的手機，就能完成連鎖超商等級的管理。

## 2. 核心功能介紹

### 🛒 智慧結帳櫃台
*   **極速掃碼**：利用手機鏡頭連續掃描商品條碼（支援 EAN-13 等常見格式）。
*   **手動輸入**：針對條碼磨損的商品，提供手動輸入補救機制。
*   **購物車管理**：可即時增減數量，即時計算總金額。
*   **多元支付**：記錄現金、Line Pay 或賒帳等付款方式。
*   **收銀音效**：結帳成功時發出清脆的 "Cha-Ching" 收銀聲，提升互動感。

### 📦 進貨與商品管理
*   **雙模式辨識**：
    *   **快速補貨**：掃描舊商品，自動帶出資訊，僅需輸入進貨數量。
    *   **新品建檔**：掃描新條碼，自動進入建檔介面。
*   **商品分類**：支援自訂類別（如：食品、飲品、生活用品），利於後續分析。
*   **圖片壓縮技術**：拍照建檔時，系統自動將高畫質照片壓縮至 Web 友善大小 (Base64)，確保存入資料庫不卡頓。
*   **效期管理**：進貨時可輸入有效期限，系統自動追蹤。

### 📊 營收與利潤分析
*   **堆疊長條圖 (Stacked Bar)**：直觀顯示每日/每週的「營收結構」。
    *   **下層 (橘色)**：進貨成本。
    *   **上層 (綠色)**：淨利潤。
    *   *一眼看出錢是賺進口袋，還是拿去付貨款。*
*   **類別圓餅圖 (Pie Chart)**：切換檢視「營收來源」或「利潤來源」，找出店內的黃金商品類別。
*   **長期趨勢**：提供「近半年」的月報表分析。

### 🚨 倉儲監控中心
*   **缺貨/即期預警**：自動篩選庫存低於安全水位，或即將過期的商品。
*   **熱銷排行**：依據銷量排序，協助判斷進貨策略。
*   **全商品清單**：瀏覽店內所有商品，點擊即可快速跳轉編輯。

### ⚙️ 系統設定與資料備份
*   **財務報表匯出**：產生 Excel 可讀的 CSV 檔，包含每一筆交易的成本與毛利，方便會計作帳。
*   **完整系統備份**：匯出 JSONL 檔案（含圖片與歷史紀錄），支援 **「匯入還原」** 功能，換手機也能無縫接軌。

## 3. 使用說明書 (User Guide)

### 第一步：商品建檔 (初始化)
1.  進入 **「進貨」** 頁面。
2.  點擊掃描器或輸入條碼。
3.  若是新商品，填寫名稱、分類、售價、成本。
4.  強烈建議拍攝商品照（系統會自動壓縮），方便辨識。
5.  設定「警示值」（例如剩 5 個要通知）。

### 第二步：開始結帳
1.  進入 **「結帳」** 頁面。
2.  將鏡頭對準客人購買的商品條碼，聽到「嗶」聲即加入購物車。
3.  確認金額無誤，點擊 **「結帳收款」**。
4.  選擇付款方式，系統播放收銀音效，交易完成並自動扣庫存。

### 第三步：查看業績
1.  進入 **「分析」** 頁面。
2.  切換「今日」、「本週」或「近半年」。
3.  觀察長條圖的綠色部分（淨利）是否健康。
4.  觀察圓餅圖，確認哪個類別賣得最好。

### 第四步：資料備份 (重要！)
1.  由於這是離線網頁 App，資料存在您的手機瀏覽器中。
2.  請定期至 **「設定」** 頁面，點擊 **「匯出備份」**，將檔案存在手機檔案夾或雲端硬碟，以防手機遺失。

## 5. 技術架構

*   **前端核心**：HTML5、CSS3、Vanilla JavaScript，不需編譯。
*   **資料存儲**：Browser LocalStorage（沿用 V7 的 key，舊資料會自動升級）。
*   **離線**：`sw.js` 快取 App 本體與函式庫；`manifest.webmanifest` 讓手機可「加入主畫面」全螢幕使用。
*   **第三方套件**（放在 `vendor/`，已鎖定版本）：
    *   `html5-qrcode@2.3.8`：相機條碼辨識（支援的瀏覽器會改用原生 BarcodeDetector，速度更快）。
    *   `chart.js@4.4.1`：報表圖表。

```
index.html             App 本體
sw.js                  離線快取
manifest.webmanifest   PWA 設定
icon.svg               App 圖示
vendor/                第三方函式庫
```

## 6. 如何開始 (Installation)

手機瀏覽器只允許 **https** 網址使用相機，因此建議用 GitHub Pages 部署：

1.  到 GitHub repo 的 **Settings → Pages**，Source 選 `main` 分支根目錄，儲存。
2.  用手機 Chrome / Safari 開啟 `https://<帳號>.github.io/ScanBoss/`，允許相機權限。
3.  選「加入主畫面」，之後就像一般 App 一樣使用，沒有網路也能開。

本機開發：在專案資料夾執行 `python -m http.server`，開啟 `http://localhost:8000`（localhost 也可使用相機）。

> **資料提醒**：資料只存在這台裝置的瀏覽器。請定期在「設定 → 備份全部資料」下載備份檔，並存到雲端硬碟。
